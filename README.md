# LAST LINE

A small survival shooter developed with Unity. / Unity で開発したサバイバルシューティング・ミニゲームです。 / 使用 Unity 开发的生存射击小游戏。

## 中文

玩家在画面底部左右移动并用鼠标瞄准射击，阻止敌人突破防线。击败敌人可获得经验并选择强化；各路线的防御地雷会自动消灭首次突破的敌人，地雷耗尽后三次突破即游戏结束。

## 日本語

画面下部を左右に移動し、マウスで照準・射撃して敵の防衛ライン突破を阻止します。敵を倒すと経験値を獲得し、レベルアップ時に強化を選択できます。各レーンの防衛地雷は最初に侵入した敵を自動で倒し、地雷消費後に3回突破されるとゲームオーバーです。

## English

Move along the bottom of the screen, aim with the mouse, and shoot enemies before they cross the defense line. Defeated enemies grant experience and upgrade choices. Each lane has a defensive mine that stops its first breach; after the mines are gone, three breaches end the run.

## Controls / 操作

- Move / 移動: `A` / `D` or Left / Right Arrow
- Aim / 照準 / 瞄准: Mouse
- Fire / 射撃 / 射击: Hold Left Mouse Button
- Start or restart / 開始・リスタート / 开始或重新开始: `Space`
- Choose an upgrade / 強化選択 / 选择强化: `1`, `2`, `3`, or click a card
- Return to title / タイトルへ戻る / 返回标题: `Esc`
